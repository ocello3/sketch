# overview
音声を再生し、その FFT の結果を螺旋状に並んだ長方形バーの形と明るさにフィードバックしています。

# concept
- 音声は wav をループ再生します。
- 低域/高域を調整するために lowpass フィルタを通します。
- FFT で周波数スペクトルを取得し、各周波数帯に対応するバーの高さと透明度を決めます。
- 各バーはフェルマー螺旋上に配置され、回転しながら描画されます。
- フィルタの cutoff と resonance は、螺旋上の位置に応じて変化させます。

# visual structure
- 螺旋の式はフェルマー螺旋を使用しています。
  - $r = a \sqrt{\theta}$
- 各点に縦方向の長方形を配置します。
- 長方形の高さは FFT の強度に応じて変化します。
- 高さが大きいほど濃い塗りで描画され、低い値は透明に近づきます。
- 画面外に出たら再配置されるように、螺旋の開始位置をリセットします。

# sound structure
- 音声ファイルは apollo-1.wav を読み込みます。
- 再生時にはループ再生を行い、回転速度に応じて再生速度も変化させます。
- フィルタは以下のように制御します。
  - cutoff: 螺旋上の最初の点の x 座標に応じて変化
  - resonance: 螺旋上の半径に応じて変化

# parameters
Tweakpane で以下のパラメータを操作できます。

## sketch
- rotateVel: 螺旋の回転速度
- barSizeRate: FFT の強度をバーの長さに変換する倍率
- laps: 螺旋が何周するか
- radiusRate: 螺旋の半径拡大率

## sound
- res: フィルタの resonance
- freq: フィルタの cutoff 周波数
- vol: 音量設定
- isInit: 初期化フラグ
- play: 再生状態フラグ
